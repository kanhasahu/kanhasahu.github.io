# Kanha Sahu - Resume & Portfolio

A modern React & Vite digital resume and portfolio for Kanha Sahu, rewritten from the classic Start Bootstrap Resume theme.

## Features Preserved
- **About Section**: Full profile information, contact links, bio, and social actions (LinkedIn, GitHub, Resume/CV export).
- **Experience Section**: Professional employment history at Impelsys, PROVAB TECHNOSOFT PVT. LTD., and Ballyhoo Consultancy Services PVT. LTD., with detailed responsibilities.
- **Education Section**: Academic background from Chhattisgarh Engineering College and secondary institutions.
- **Skills & Workflow**: Complete set of developer icons (PHP, MySQL, MS SQL, GitHub, Docker, Symfony, HTML5, CSS3, JavaScript, Angular, React, Node.js, Sass, Less, WordPress, Gulp, Grunt, npm) and agile workflow practices.
- **Responsive Layout**: Desktop fixed side navigation bar and mobile responsive slide drawer.
- **Interactive Enhancements**: Dynamic scrollspy navigation and integrated printable CV preview / plain-text export modal.

## Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build production bundle
npm run build
```
